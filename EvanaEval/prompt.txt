Build a small web application called "RepoPulse" inside the EvanaEval workspace.

The application should allow a user to enter a public GitHub repository URL and see a simple analysis of that repository.

Before implementing anything, research the official GitHub REST API documentation relevant to:
- repository information
- repository languages
- repository contributors

Use the official GitHub documentation as the primary source.

Requirements:

1. Create the project from scratch inside EvanaEval/repopulse.

2. Build a small web application with:
   - a simple page containing a repository URL input
   - an Analyze button
   - a results section

3. When the user enters a public GitHub repository such as:
   https://github.com/NxFi3/SimpleDL

   the application should retrieve and display:
   - repository name
   - description
   - stars
   - forks
   - primary language
   - language statistics
   - number of contributors

4. Handle common failures gracefully:
   - invalid GitHub URL
   - repository not found
   - GitHub API failure
   - malformed API response

5. Keep the project simple.
   Do not install unnecessary dependencies.
   Prefer the standard library where practical.

6. Add automated tests for the API/data-processing logic.
   Tests should not depend on live GitHub requests; mock or isolate the API layer.

7. Run the complete test suite.

8. Start the application locally and verify that it launches successfully.

9. Perform at least one real request against a public GitHub repository to verify that the application works with the actual GitHub API.

10. Inspect the final project and make sure the README explains:
    - how to run it
    - how to run the tests
    - what GitHub API endpoints are used
    - any limitations

11. Do not modify anything outside the new project.
12. Do not install packages globally.
13. If several independent web searches are needed, perform them efficiently.
14. Use multiple smaller implementation steps when appropriate instead of trying to generate the entire project in one enormous patch.

- what you researched
