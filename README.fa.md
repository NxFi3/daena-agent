# راهنمای فارسی — Daena Computer Use 1.0

این بسته جایگزین پوشهٔ `computer_use` فایل ارسالی است. خود Daena یا مدل را عوض
نمی‌کند؛ مشاهده، ورودی دسکتاپ و بررسی نتیجه را بازطراحی می‌کند.

## نصب برای Daena 0.6

Daena را ببند. ZIP را باز کن و داخل پوشهٔ همین بسته اجرا کن:

```bash
conda activate AI
python -m pip install -e '.[viewer]'
python install_into_daena.py --repo ~/Desktop/daena-0.6.0 --wire-runtime --enable
```

مسیر `--repo` را با مسیر واقعی پروژه جایگزین کن. فایل‌های قبلی در
`.daena-computer-use-backups` بکاپ گرفته می‌شوند. Daena را دوباره اجرا کن و
اگر workspace قبلی انتخاب ابزار مستقل دارد، `computer_use` را در Tools فعال کن.

اگر نسخهٔ فعلی Daena از قبل `image_ref` را به مدل می‌فرستد و workspace/توقف را
به ابزار وصل می‌کند، `--wire-runtime` را حذف کن؛ این گزینه برای اتصال نسخهٔ
۰.۶ استاندارد است. نصب‌کننده ساختار ناشناس را حدس نمی‌زند.

درایور خارجی `cua-driver` داخل ZIP نیست؛ همان وابستگی نسخهٔ قبلی تو است:

```bash
cua-driver doctor
daena-computer doctor
```

نمایشگر تاریخچهٔ اجرا:

```bash
daena-computer-viewer ~/Desktop/test
```

اسکرول برای زوم، کشیدن تصویر برای جابه‌جایی، Fit برای کل تصویر و 100% برای
اندازهٔ واقعی است. این نمایشگر خودش اقدامی روی دسکتاپ انجام نمی‌دهد.

## تغییرات مهم

- هر ورودی به `snapshot_id` آخرین مشاهده متصل است؛ شناسهٔ قدیمی دوباره استفاده نمی‌شود.
- محدودیت حدسی «بعد از چهار کلیک متوقف شو» و قواعد اختصاصی سایت‌ها حذف شده‌اند.
- ثابت ماندن تصویر شکست قطعی نیست؛ تغییر تصویر هم اثبات موفقیت نیست.
- شرط‌هایی مثل تیک‌خوردن یک گزینه یا تغییر مقدار فیلد قابل بررسی‌اند.
- timeout باعث ارسال دوبارهٔ خودکار کلیک/تایپ نمی‌شود.
- عملیات چند ایجنت روی یک دسکتاپ با یکدیگر تداخل نمی‌کنند.
- آفست ثابت نوار عنوان حذف شده؛ مختصات نامطمئن حدس زده نمی‌شوند.
- زوم ناحیه‌ای تصویر، توقف، گزارش اجرا و تایپ فارسی اضافه/تست شده‌اند.

مدل باید قابلیت دیدن تصویر داشته باشد و host تصویر را واقعاً به آن برساند.
توانایی استدلال مدل با تعویض ابزار تغییر نمی‌کند. تست واقعی دسکتاپ روی X11
و یک برنامهٔ Qt انجام شده؛ اجرای Cua روی Wayland سیستم تو هنوز بررسی نشده.
جزئیات در `VALIDATION.md` و قرارداد جدید در `docs/protocol.md` است.
